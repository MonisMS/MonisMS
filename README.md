### Projects

- **[APIx](https://github.com/MonisMS/apix-dashboard)**: a daily airfare price index for India. Collects fares across 12 DGCA-weighted routes and 5 advance-purchase windows, then computes a Jevons/Young index that reproduces MoSPI's published worked examples to four decimal places. 24,448 fares collected so far. [Live](https://apix-dashboard-gitbashers.vercel.app)
- **[Curio](https://github.com/MonisMS/article-it)**: one reading feed from 275+ sources across 26 topics. Parallel ingestion with per-source timeouts, quality-scored ranking, Postgres full-text search and timezone-aware email digests. [Live](https://curio-sity.vercel.app)
- **[FieldProof](https://github.com/MonisMS/cc-hack)**: field photos in, verifiable impact reports out. A Python worker tags photos with CLIP, embeds them for pgvector search and assigns sites from EXIF GPS. AI reports that invent a number are rejected. Built at Code Cubicle 6.0. [Live](https://cc-hack-pi.vercel.app)
- **[DataPilot](https://github.com/MonisMS/cc-general-hack-ps)**: prompt in, clean dataset out. An LLM planner picks from 9 robots.txt-aware collectors, runs them in parallel, then de-duplicates and confidence-scores every row.
- **[Shikshak Saathi](https://github.com/MonisMS/shikshak-saathi)**: turns any NCERT chapter into a lesson plan, worksheet and misconception-tagged quiz, in English and Hindi. Built at Hack-e-Awadh 2026. [Live](https://shikshak-saathi.vercel.app)
